WEB LUYỆN VIẾT LẠI CÂU
======================
Mở index.html bằng Chrome, Edge, Firefox, Safari. Không cần mạng.

Để đưa lên GitHub Pages: upload index.html lên thư mục gốc của repo và bật Settings > Pages.
questions.json là dữ liệu đối chiếu câu hỏi được trích từ 2 file Word.

Quy tắc: giữ thứ tự câu hỏi trong mỗi file. Mỗi lần làm lại chỉ xáo trộn vị trí 4 lựa chọn trong từng câu.
Đáp án được chấm chỉ khi file Word có dấu ✅ hoặc làm nổi bật màu đỏ duy nhất. Không xác minh ngữ pháp ngoài tài liệu.
